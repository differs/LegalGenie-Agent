## 一、需求分析

### 1.1 核心需求

| 需求 | 说明 | 优先级 |
|------|------|--------|
| 用户注册 | 邮箱/手机号注册 | P0 |
| 用户登录 | 账号密码登录、记住登录 | P0 |
| 密码管理 | 修改密码、找回密码 | P0 |
| 角色权限 | 管理员/主办律师/律师助理 | P0 |
| 案件权限 | 案件级访问控制 | P0 |
| Token 管理 | JWT、刷新 Token | P0 |
| 登录日志 | 记录登录时间、IP | P1 |
| 多端登录 | 支持多设备同时登录 | P2 |

### 1.2 角色定义

| 角色 | 权限 | 说明 |
|------|------|------|
| **管理员** | 全部权限 | 用户管理、系统配置 |
| **主办律师** | 案件管理、团队管理 | 创建案件、分配团队成员 |
| **律师助理** | 案件编辑、文件上传 | 协助主办律师处理案件 |
| **访客** | 只读权限 | 仅限查看指定案件 |

### 1.3 权限模型

```
RBAC（基于角色的访问控制）

用户 → 角色 → 权限
      ↓
   案件权限（数据级权限）
```

## 三、认证流程设计

### 3.1 JWT Token 结构

```rust
// src/models/auth.rs
use chrono::{DateTime, Utc, Duration};
use serde::{Deserialize, Serialize};

/// JWT Claims
#[derive(Debug, Clone, Serialize, Deserialize)]
pub struct Claims {
    /// 用户 ID
    pub sub: String,
    /// 用户名
    pub username: String,
    /// 角色列表
    pub roles: Vec<String>,
    /// 过期时间
    pub exp: usize,
    /// 签发时间
    pub iat: usize,
    /// Token 类型
    pub token_type: TokenType,
}

/// Token 类型
#[derive(Debug, Clone, Serialize, Deserialize, PartialEq)]
pub enum TokenType {
    Access,     // 访问 Token（短期）
    Refresh,    // 刷新 Token（长期）
}

impl Claims {
    /// 创建访问 Token
    pub fn new_access(user_id: String, username: String, roles: Vec<String>) -> Self {
        let now = Utc::now();
        let exp = now + Duration::minutes(60); // 1 小时有效期
        
        Self {
            sub: user_id,
            username,
            roles,
            exp: exp.timestamp() as usize,
            iat: now.timestamp() as usize,
            token_type: TokenType::Access,
        }
    }
    
    /// 创建刷新 Token
    pub fn new_refresh(user_id: String) -> Self {
        let now = Utc::now();
        let exp = now + Duration::days(7); // 7 天有效期
        
        Self {
            sub: user_id,
            username: String::new(),
            roles: Vec::new(),
            exp: exp.timestamp() as usize,
            iat: now.timestamp() as usize,
            token_type: TokenType::Refresh,
        }
    }
}
```

### 3.2 认证服务

```rust
// src/services/auth_service.rs
use argon2::{password_hash::PasswordHash, Argon2, PasswordVerifier};
use jsonwebtoken::{encode, decode, Header, Algorithm, Validation};
use crate::models::auth::*;

pub struct AuthService {
    pool: SqlitePool,
    secret: String,
}

impl AuthService {
    pub fn new(pool: SqlitePool, secret: String) -> Self {
        Self { pool, secret }
    }
    
    /// 用户登录
    pub async fn login(
        &self,
        username: &str,
        password: &str,
        ip_address: Option<&str>,
        user_agent: Option<&str>,
    ) -> Result<LoginResponse, AuthError> {
        // 1. 查询用户
        let user = self.find_user_by_username(username).await?
            .ok_or(AuthError::InvalidCredentials)?;
        
        // 2. 验证密码
        let parsed_hash = PasswordHash::new(&user.password_hash)
            .map_err(|_| AuthError::InvalidCredentials)?;
        
        let valid = Argon2::default()
            .verify_password(password.as_bytes(), &parsed_hash)
            .is_ok();
        
        if !valid {
            // 记录登录失败
            self.log_login(&user.id, false, ip_address, user_agent, Some("密码错误")).await?;
            return Err(AuthError::InvalidCredentials);
        }
        
        // 3. 检查用户状态
        if user.status != "active" {
            return Err(AuthError::UserInactive);
        }
        
        // 4. 获取用户角色
        let roles = self.get_user_roles(&user.id).await?;
        
        // 5. 生成 Token
        let access_token = self.generate_access_token(&user.id, &user.username, &roles)?;
        let refresh_token = self.generate_refresh_token(&user.id)?;
        
        // 6. 更新最后登录时间
        self.update_last_login(&user.id, ip_address).await?;
        
        // 7. 记录登录日志
        self.log_login(&user.id, true, ip_address, user_agent, None).await?;
        
        Ok(LoginResponse {
            user: UserInfo::from_user(user),
            access_token,
            refresh_token,
            expires_in: 3600,
        })
    }
    
    /// 刷新 Token
    pub async fn refresh_token(&self, refresh_token: &str) -> Result<TokenResponse, AuthError> {
        // 验证刷新 Token
        let claims = self.verify_token(refresh_token)?;
        
        if claims.token_type != TokenType::Refresh {
            return Err(AuthError::InvalidToken);
        }
        
        // 生成新的访问 Token
        let user = self.find_user_by_id(&claims.sub).await?
            .ok_or(AuthError::UserNotFound)?;
        
        let roles = self.get_user_roles(&user.id).await?;
        let access_token = self.generate_access_token(&user.id, &user.username, &roles)?;
        
        Ok(TokenResponse {
            access_token,
            expires_in: 3600,
        })
    }
    
    /// 验证 Token
    pub fn verify_token(&self, token: &str) -> Result<Claims, AuthError> {
        let validation = Validation::new(Algorithm::HS256);
        let decoded = decode::<Claims>(
            token,
            self.secret.as_bytes(),
            &validation,
        )?;
        
        Ok(decoded.claims)
    }
    
    /// 检查权限
    pub async fn check_permission(
        &self,
        user_id: &str,
        case_id: &str,
        required_permission: &str,
    ) -> Result<bool, AuthError> {
        // 1. 获取用户角色
        let roles = self.get_user_roles(user_id).await?;
        
        // 2. 检查是否是管理员
        if roles.contains(&"admin".to_string()) {
            return Ok(true);
        }
        
        // 3. 检查案件权限
        let case_role = self.get_case_role(user_id, case_id).await?;
        
        match case_role.as_deref() {
            Some("owner") => Ok(true),  // 案件所有者
            Some("member") => {
                // 检查角色权限
                self.has_permission_in_roles(&roles, required_permission).await
            },
            Some("viewer") => Ok(false),  // 访客无编辑权限
            None => Ok(false),
        }
    }
}

/// 登录响应
#[derive(Debug, Clone, Serialize, Deserialize)]
pub struct LoginResponse {
    pub user: UserInfo,
    pub access_token: String,
    pub refresh_token: String,
    pub expires_in: i64,
}

/// Token 响应
#[derive(Debug, Clone, Serialize, Deserialize)]
pub struct TokenResponse {
    pub access_token: String,
    pub expires_in: i64,
}

/// 用户信息
#[derive(Debug, Clone, Serialize, Deserialize)]
pub struct UserInfo {
    pub id: String,
    pub username: String,
    pub email: String,
    pub real_name: Option<String>,
    pub avatar_url: Option<String>,
    pub roles: Vec<String>,
}
```

### 4.3 权限检查中间件

```rust
// src/middleware/auth.rs
use axum::{
    extract::State,
    http::{Request, StatusCode},
    middleware::Next,
    response::Response,
};

/// 认证中间件
pub async fn auth_middleware<B>(
    mut request: Request<B>,
    next: Next<B>,
) -> Result<Response, StatusCode> {
    // 从 Header 获取 Token
    let auth_header = request
        .headers()
        .get(http::header::AUTHORIZATION)
        .and_then(|h| h.to_str().ok())
        .and_then(|s| s.strip_prefix("Bearer "));
    
    let token = auth_header.ok_or(StatusCode::UNAUTHORIZED)?;
    
    // 验证 Token
    let state = request.extensions().get::<Arc<AppState>>().unwrap();
    let claims = state.auth_service.verify_token(token)
        .map_err(|_| StatusCode::UNAUTHORIZED)?;
    
    // 将用户信息注入请求
    request.extensions_mut().insert(claims);
    
    Ok(next.run(request).await)
}

/// 权限检查中间件
pub async fn permission_middleware<B>(
    required_permission: str,
    mut request: Request<B>,
    next: Next<B>,
) -> Result<Response, StatusCode> {
    let claims = request.extensions().get::<Claims>()
        .ok_or(StatusCode::UNAUTHORIZED)?;
    
    let case_id = request.extensions().get::<String>()
        .ok_or(StatusCode::BAD_REQUEST)?;
    
    let state = request.extensions().get::<Arc<AppState>>().unwrap();
    
    let has_permission = state.auth_service
        .check_permission(&claims.sub, case_id, required_permission)
        .await
        .map_err(|_| StatusCode::INTERNAL_SERVER_ERROR)?;
    
    if !has_permission {
        return Err(StatusCode::FORBIDDEN);
    }
    
    Ok(next.run(request).await)
}
```

```rust
// frontend/src/router.rs

#[component]
pub fn ProtectedRoute(children: Element, required_permission: Option<String>) -> Element {
    let user = use_context::<Signal<Option<UserInfo>>>();
    let mut navigate = use_navigator();
    
    // 检查是否登录
    if user().is_none() {
        use_effect(move || {
            navigate.push("/login");
        });
        return rsx! { div { "跳转中..." } };
    }
    
    // 检查权限（如果有要求）
    if let Some(permission) = required_permission {
        if !user().unwrap().permissions.contains(&permission) {
            return rsx! {
                div { class: "no-permission",
                    h1 { "无权限访问" }
                    p { "您没有访问此页面的权限" }
                }
            };
        }
    }
    
    children
}
```

## 六、安全设计

### 6.1 密码安全

```rust
// 密码加密（Argon2）
use argon2::{PasswordHasher, Algorithm, Params, Version};

pub fn hash_password(password: &str) -> Result<String, anyhow::Error> {
    let salt = SaltString::generate(&mut OsRng);
    
    let argon2 = Argon2::new(
        Algorithm::Argon2id,
        Version::V0x13,
        Params::new(19456, 2, 1, None)?, // 内存 19MB, 2 次迭代，1 并行度
    );
    
    let hash = argon2.hash_password(password.as_bytes(), &salt)?;
    Ok(hash.to_string())
}
```

### 6.3 防爆破

```rust
// 登录失败限制
pub async fn check_login_attempts(
    username: &str,
    ip_address: &str,
) -> Result<(), AuthError> {
    // 检查用户名级别失败次数
    let user_failures = get_failed_attempts_by_user(username).await?;
    if user_failures >= 5 {
        return Err(AuthError::TooManyAttempts);
    }
    
    // 检查 IP 级别失败次数
    let ip_failures = get_failed_attempts_by_ip(ip_address).await?;
    if ip_failures >= 10 {
        return Err(AuthError::TooManyAttempts);
    }
    
    Ok(())
}
```
