## 一、需求分析

### 1.1 核心功能

| 功能 | 说明 | 优先级 |
|------|------|--------|
| 时间轴展示 | 按时间顺序展示事件节点 | P0 |
| 节点创建 | 手动创建事件节点 | P0 |
| 节点编辑 | 修改时间、标题、描述 | P0 |
| 拖拽排序 | 拖动节点调整时间顺序 | P0 |
| 证据关联 | 节点关联多份证据 | P0 |
| 双向跳转 | 点击节点跳转证据原文 | P0 |
| 缩放导航 | 放大/缩小时间轴，快速定位 | P1 |
| 筛选过滤 | 按标签/类型/关键词筛选 | P1 |
| 节点分组 | 按人物/事件类型分组显示 | P2 |
| 关系连线 | 节点间因果关系连线 | P2 |
| 导出图片 | 时间轴导出为 PNG/PDF | P2 |

### 1.2 用户场景

```
场景 1：浏览案件全貌
律师打开案件 → 查看时间轴 → 快速了解事件发展脉络

场景 2：添加新证据
上传新证据 → 创建节点 → 关联证据 → 拖拽到正确时间位置

场景 3：发现矛盾
发现两个节点时间冲突 → 拖拽调整 → 系统提示时间重叠

场景 4：庭审准备
筛选关键节点 → 导出时间轴 → 打印/展示给法官
```

/// 视图范围
#[derive(Clone, Copy, PartialEq)]
pub struct ViewRange {
    pub start: chrono::NaiveDate,
    pub end: chrono::NaiveDate,
}

impl ViewRange {
    pub fn fit_all(nodes: &[TimelineNode]) -> Self {
        if nodes.is_empty() {
            let now = chrono::Utc::now().naive_utc().date();
            Self {
                start: now - chrono::Duration::days(30),
                end: now + chrono::Duration::days(30),
            }
        } else {
            let min = nodes.iter().map(|n| n.event_time).min().unwrap();
            let max = nodes.iter().map(|n| n.event_time).max().unwrap();
            Self {
                start: min - chrono::Duration::days(7),
                end: max + chrono::Duration::days(7),
            }
        }
    }
}

#[component]
pub fn TimelineRuler(view_range: ViewRange, zoom_level: f64) -> Element {
    let days = (view_range.end - view_range.start).num_days() as f64;
    let pixels_per_day = 50.0 * zoom_level;
    
    // 计算刻度间隔
    let tick_interval = if days < 30.0 {
        TickInterval::Day
    } else if days < 90.0 {
        TickInterval::Week
    } else if days < 365.0 {
        TickInterval::Month
    } else {
        TickInterval::Year
    };
    
    rsx! {
        div { class: "timeline-ruler", style: "height: 40px;",
            // 主刻度
            for tick in generate_ticks(view_range, tick_interval) {
                div {
                    class: "ruler-tick",
                    style: format!("left: {}px; width: {}px;", 
                           (tick.date - view_range.start).num_days() as f64 * pixels_per_day,
                           tick_interval.width_days() as f64 * pixels_per_day),
                    
                    // 刻度线
                    div { class: "tick-line" }
                    
                    // 刻度标签
                    span { class: "tick-label",
                        {tick.label}
                    }
                }
            }
            
            // 今天标记线
            if is_date_in_range(chrono::Utc::now().naive_utc().date(), view_range) {
                div {
                    class: "today-marker",
                    style: format!("left: {}px;",
                        (chrono::Utc::now().naive_utc().date() - view_range.start).num_days() as f64 * pixels_per_day),
                    "今天"
                }
            }
        }
    }
}

#[derive(Clone, Copy, PartialEq)]
pub enum TickInterval {
    Day,
    Week,
    Month,
    Year,
}

impl TickInterval {
    pub fn width_days(self) -> i64 {
        match self {
            TickInterval::Day => 1,
            TickInterval::Week => 7,
            TickInterval::Month => 30,
            TickInterval::Year => 365,
        }
    }
}

// frontend/src/utils/timeline_dnd.rs

/// 处理节点拖拽
pub fn handle_node_drag(
    node_id: &str,
    drag_x: f64,
    view_range: ViewRange,
    pixels_per_day: f64,
) -> chrono::NaiveDate {
    // 计算拖拽后的日期
    let start_x = (view_range.start - chrono::NaiveDate::from_ymd(1970, 1, 1)).num_days() as f64 * pixels_per_day;
    let dragged_days = (drag_x - start_x) / pixels_per_day;
    
    view_range.start + chrono::Duration::days(dragged_days as i64)
}

/// 检测时间冲突
pub fn check_time_conflict(
    nodes: &[TimelineNode],
    node_id: &str,
    new_time: chrono::NaiveDate,
    threshold_days: i64 = 0,
) -> Vec<ConflictInfo> {
    let mut conflicts = Vec::new();
    
    for node in nodes {
        if node.id != node_id {
            let days_diff = (node.event_time - new_time).num_days().abs();
            if days_diff <= threshold_days {
                conflicts.push(ConflictInfo {
                    node_id: node.id.clone(),
                    node_title: node.title.clone(),
                    conflict_type: if days_diff == 0 {
                        ConflictType::SameDay
                    } else {
                        ConflictType::Nearby
                    },
                });
            }
        }
    }
    
    conflicts
}

#[derive(Debug, Clone)]
pub struct ConflictInfo {
    pub node_id: String,
    pub node_title: String,
    pub conflict_type: ConflictType,
}

#[derive(Debug, Clone, PartialEq)]
pub enum ConflictType {
    SameDay,    // 同一天
    Nearby,     // 临近
}

pub fn use_virtual_timeline(
    nodes: Signal<Vec<TimelineNode>>,
    view_range: Signal<ViewRange>,
    container_height: Signal<f64>,
) -> Signal<Vec<TimelineNode>> {
    use_memo(move || {
        let all_nodes = nodes();
        let range = view_range();
        let height = container_height();
        
        // 计算可见区域
        let visible_start = range.start;
        let visible_days = height / 50.0; // 每节点约 50px
        let visible_end = visible_start + chrono::Duration::days(visible_days as i64);
        
        // 只渲染可见区域的节点
        let visible_nodes: Vec<TimelineNode> = all_nodes
            .into_iter()
            .filter(|n| n.event_time >= visible_start && n.event_time <= visible_end)
            .collect();
        
        visible_nodes
    })
}

## 七、导出功能

### 7.1 导出为图片

```rust
// frontend/src/utils/timeline_export.rs

pub async fn export_timeline_as_png(
    case_id: &str,
    view_range: ViewRange,
) -> anyhow::Result<Vec<u8>> {
    // 1. 获取节点数据
    let nodes = fetch_timeline_nodes(case_id).await?;
    
    // 2. 创建离屏 Canvas
    let canvas = create_offscreen_canvas(2000, 1500);
    let ctx = canvas.get_context_2d().unwrap();
    
    // 3. 绘制背景
    ctx.set_fill_style("#fff");
    ctx.fill_rect(0.0, 0.0, 2000.0, 1500.0);
    
    // 4. 绘制时间刻度
    draw_ruler(&ctx, view_range);
    
    // 5. 绘制节点
    for node in &nodes {
        draw_node(&ctx, node, view_range);
    }
    
    // 6. 导出为 PNG
    let png_data = canvas.to_data_url("image/png")?;
    
    Ok(png_data)
}
```

### 7.2 导出为 PDF

```rust
// 使用 pdf crate 生成 PDF
use pdf::document::Document;
use pdf::font::Font;

pub fn export_timeline_as_pdf(
    nodes: &[TimelineNode],
    case_name: &str,
) -> anyhow::Result<Vec<u8>> {
    let mut doc = Document::new();
    
    // 添加封面
    doc.add_page()
        .text(format!("{} - 时间轴", case_name))
        .font_size(24)
        .position(50, 50);
    
    // 添加时间轴内容
    let mut y = 100;
    for node in nodes {
        doc.add_page()
            .text(&node.title)
            .font_size(12)
            .position(50, y);
        
        doc.add_page()
            .text(&format!("{}", node.event_time))
            .font_size(10)
            .position(50, y + 15);
        
        y += 30;
    }
    
    // 导出 PDF
    let pdf_data = doc.save()?;
    Ok(pdf_data)
}
```

### 8.1 技术选型

| 组件 | 技术选型 | 理由 |
