## 一、问题分析

### 1.1 典型场景

```
场景 1：同名不同人
- 张三（原告，1980 年出生，XXX 公司法人）
- 张三（证人，1995 年出生，自由职业者）

场景 2：同名 + 同电话（可能是同一人）
- 张三（电话：138****1234，原告）
- 张三（电话：138****1234，证据签署人）
→ 系统应提示"可能是同一人"

场景 3：同名 + 不同电话（需要人工判断）
- 张三（电话：138****1234，北京）
- 张三（电话：139****5678，上海）
→ 系统应标记为"待确认"
```

### 1.2 核心挑战

| 挑战 | 说明 | 解决思路 |
|------|------|----------|
| 如何区分 | 同名但不同人 | 多字段组合识别 |
| 如何提示 | 避免误合并 | 置信度评分 + 人工确认 |
| 如何合并 | 确认是同一人后 | 合并功能 + 操作日志 |
| 如何拆分 | 误合并后 | 拆分功能 + 历史追溯 |

// src/utils/person_fingerprint.rs
use sha2::{Sha256, Digest};

/// 计算人物特征指纹
/// 用于快速判断两个人是否可能相同
pub fn calculate_person_fingerprint(
    name: &str,
    birth_date: Option<&str>,
    phone: Option<&str>,
    org: Option<&str>,
) -> String {
    let mut hasher = Sha256::new();
    
    // 姓名（标准化后）
    hasher.update(name.trim().to_lowercase().as_bytes());
    
    // 出生日期（如有）
    if let Some(birth) = birth_date {
        hasher.update(birth.as_bytes());
    }
    
    // 电话（标准化后）
    if let Some(p) = phone {
        hasher.update(normalize_phone(p).as_bytes());
    }
    
    // 单位（标准化后）
    if let Some(o) = org {
        hasher.update(o.trim().to_lowercase().as_bytes());
    }
    
    let result = hasher.finalize();
    format!("{:x}", result)
}

/// 标准化电话号码
fn normalize_phone(phone: &str) -> String {
    // 移除空格、横线、括号
    phone.chars()
        .filter(|c| c.is_ascii_digit() || c == &'+' || c == &'#')
        .collect()
}

## 三、同名识别策略

### 3.1 多层级识别

```rust
// src/services/person_identification.rs

/// 同名识别结果
#[derive(Debug, Clone)]
pub struct SameNameIdentification {
    pub person_id: String,
    pub name: String,
    pub is_same_person: bool,     // 是否同一人
    pub confidence: f64,          // 置信度 0-1
    pub matched_fields: Vec<String>, // 匹配的字段
    pub different_fields: Vec<String>, // 不同的字段
    pub action_required: ActionRequired, // 需要采取的行动
}

#[derive(Debug, Clone, PartialEq)]
pub enum ActionRequired {
    AutoMerge,      // 自动合并（置信度>0.95）
    SuggestMerge,   // 建议合并（置信度 0.7-0.95）
    ManualReview,   // 人工审核（置信度 0.3-0.7）
    ConfirmSeparate, // 确认是不同人（置信度<0.3）
}

/// 识别服务
pub struct PersonIdentificationService {
    pool: SqlitePool,
}

impl PersonIdentificationService {
    /// 检查新人物是否与现有人物重复
    pub async fn check_duplicate(
        &self,
        input: &CreatePersonInput,
    ) -> anyhow::Result<Vec<SameNameIdentification>> {
        let mut results = Vec::new();
        
        // 1. 精确匹配（身份证/电话哈希）
        if let Some(exact_match) = self.find_exact_match(input).await? {
            results.push(SameNameIdentification {
                person_id: exact_match.id,
                name: exact_match.name,
                is_same_person: true,
                confidence: 1.0,
                matched_fields: vec!["id_number".to_string()],
                different_fields: vec![],
                action_required: ActionRequired::AutoMerge,
            });
            return Ok(results); // 精确匹配，直接返回
        }
        
        // 2. 查找同名人物
        let same_name_persons = self.find_same_name_persons(&input.name).await?;
        
        for person in same_name_persons {
            let (confidence, matched, different) = 
                self.calculate_similarity(&person, input);
            
            let action = if confidence > 0.95 {
                ActionRequired::AutoMerge
            } else if confidence > 0.7 {
                ActionRequired::SuggestMerge
            } else if confidence > 0.3 {
                ActionRequired::ManualReview
            } else {
                ActionRequired::ConfirmSeparate
            };
            
            results.push(SameNameIdentification {
                person_id: person.id,
                name: person.name.clone(),
                is_same_person: confidence > 0.5,
                confidence,
                matched_fields: matched,
                different_fields: different,
                action_required: action,
            });
        }
        
        // 按置信度排序
        results.sort_by(|a, b| b.confidence.partial_cmp(&a.confidence).unwrap());
        
        Ok(results)
    }
    
    /// 计算相似度
    fn calculate_similarity(
        &self,
        existing: &Person,
        input: &CreatePersonInput,
    ) -> (f64, Vec<String>, Vec<String>) {
        let mut score = 0.0;
        let mut total_weight = 0.0;
        let mut matched = Vec::new();
        let mut different = Vec::new();
        
        // 姓名相同（基础分，权重 0）
        // 已经过滤同名，这里是计算其他字段
        
        // 出生日期（权重 30%）
        total_weight += 0.3;
        if let (Some(e_birth), Some(i_birth)) = (&existing.birth_date, &input.birth_date) {
            if e_birth == i_birth {
                score += 0.3;
                matched.push("birth_date".to_string());
            } else {
                different.push("birth_date".to_string());
            }
        }
        
        // 电话（权重 25%）
        total_weight += 0.25;
        if let (Some(e_phone), Some(i_phone)) = (&existing.phone, &input.phone) {
            if self.normalize_phone(e_phone) == self.normalize_phone(i_phone) {
                score += 0.25;
                matched.push("phone".to_string());
            } else {
                different.push("phone".to_string());
            }
        }
        
        // 单位（权重 20%）
        total_weight += 0.2;
        if let (Some(e_org), Some(i_org)) = (&existing.organization, &input.organization) {
            let similarity = self.string_similarity(&e_org.to_lowercase(), &i_org.to_lowercase());
            if similarity > 0.8 {
                score += 0.2 * similarity;
                matched.push("organization".to_string());
            } else {
                different.push("organization".to_string());
            }
        }
        
        // 地址（权重 15%）
        total_weight += 0.15;
        if let (Some(e_addr), Some(i_addr)) = (&existing.address, &input.address) {
            let similarity = self.string_similarity(&e_addr.to_lowercase(), &i_addr.to_lowercase());
            if similarity > 0.6 {
                score += 0.15 * similarity;
                matched.push("address".to_string());
            } else {
                different.push("address".to_string());
            }
        }
        
        // 身份证后 4 位（权重 10%）
        total_weight += 0.1;
        if let (Some(e_last4), Some(i_last4)) = 
            (&existing.id_number_last4, &input.id_number_last4) {
            if e_last4 == i_last4 {
                score += 0.1;
                matched.push("id_last4".to_string());
            } else {
                different.push("id_last4".to_string());
            }
        }
        
        let final_score = if total_weight > 0.0 {
            score / total_weight
        } else {
            0.5 // 无其他信息，默认中等置信度
        };
        
        (final_score, matched, different)
    }
    
    /// 字符串相似度（Levenshtein 距离）
    fn string_similarity(&self, a: &str, b: &str) -> f64 {
        let len_a = a.len();
        let len_b = b.len();
        
        if len_a == 0 && len_b == 0 {
            return 1.0;
        }
        if len_a == 0 || len_b == 0 {
            return 0.0;
        }
        
        let distance = self.levenshtein_distance(a, b);
        1.0 - (distance as f64 / len_a.max(len_b) as f64)
    }
}
```

### 3.2 识别规则总结

| 匹配情况 | 置信度 | 处理方式 |
|----------|--------|----------|
| 身份证号相同 | 100% | 自动合并 |
| 电话相同 + 姓名相同 | 95% | 建议合并，用户确认 |
| 姓名 + 生日 + 单位相同 | 90% | 建议合并，用户确认 |
| 姓名 + 电话不同 | 80% | 提示人工审核 |
| 姓名 + 单位不同 | 60% | 提示人工审核 |
| 仅姓名相同 | 50% | 标记"待确认" |
| 姓名 + 生日不同 | 30% | 确认为不同人 |

## 七、总结

### 7.1 核心策略

| 策略 | 说明 |
|------|------|
| 多层级识别 | 身份证 > 电话 > 生日 > 单位 > 地址 |
| 置信度评分 | 0-1 分，>0.95 自动合并，0.7-0.95 建议合并 |
| 人工确认 | 中等置信度时提示用户判断 |
| 可逆操作 | 合并记录永久保存，支持拆分追溯 |
| 前端提示 | 创建/编辑时实时查重 |

### 7.2 处理流程

```
创建/编辑人物
    ↓
查重检测（同名 + 多字段匹配）
    ↓
┌─────────────────────────────────────┐
│ 置信度 > 0.95 → 自动合并，记录日志   │
│ 置信度 0.7-0.95 → 建议合并，用户确认  │
│ 置信度 0.3-0.7 → 人工审核，判断是否同人│
│ 置信度 < 0.3 → 标记为不同人          │
└─────────────────────────────────────┘
    ↓
完成创建/更新
```

### 7.3 数据量估算

| 场景 | 频率 | 存储 |
|------|------|------|
| 查重检测 | 每次创建/编辑 | 缓存 7 天 |
| 合并操作 | <1 次/案件 | 永久保存记录 |
| 拆分操作 | 罕见 | 永久保存记录 |
| 相似度缓存 | 实时计算 | 保留 30 天 |
