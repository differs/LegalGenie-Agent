## 一、整体架构

### 1.1 资料分类

| 资料类型 | 说明 | 示例 |
|----------|------|------|
| **原始证据** | 当事人提供的原始文件 | 合同.pdf、录音.mp3、聊天记录.png |
| **解析结果** | 从原始文件提取的文本和元数据 | 文字内容、页码、时间戳 |
| **衍生资料** | 系统生成的资料 | 证据清单.xlsx、时间轴图.png |
| **锚定信息** | 原始文件与节点的关联关系 | 节点→页码/时间戳映射 |

### 1.2 数据流向

```
当事人提供原始证据
        ↓
    上传系统
        ↓
┌───────────────────────────────────────┐
│           原始文件存储                 │
│  storage/files/{case_id}/{uuid}.pdf   │
└───────────────────────────────────────┘
        ↓
    解析处理
        ↓
┌───────────────────────────────────────┐
│           解析结果存储                 │
│  storage/parsed/{case_id}/{id}.json   │
│  database: evidence_files 表          │
└───────────────────────────────────────┘
        ↓
    创建节点 + 关联
        ↓
┌───────────────────────────────────────┐
│           关联关系存储                 │
│  database: node_evidence_links 表     │
│  锚定信息：页码/时间戳/坐标           │
└───────────────────────────────────────┘
        ↓
    导出资料
        ↓
┌───────────────────────────────────────┐
│           导出资料存储                 │
│  storage/exports/{case_id}/{name}     │
│  证据清单、时间轴图、案件报告         │
└───────────────────────────────────────┘
```

```rust
// src/utils/file_naming.rs
use uuid::Uuid;
use chrono::Utc;
use std::path::Path;

/// 生成存储文件名
pub fn generate_stored_name(original_name: &str) -> String {
    let uuid = Uuid::new_v4();
    let ext = Path::new(original_name)
        .extension()
        .and_then(|s| s.to_str())
        .unwrap_or("bin");
    
    // 格式：{uuid}.{ext}
    format!("{}.{}", uuid, ext.to_lowercase())
}

/// 生成解析结果文件名
pub fn generate_parsed_name(evidence_id: &str) -> String {
    format!("{}.json", evidence_id)
}

/// 生成导出文件名
pub fn generate_export_name(case_id: &str, doc_type: &str) -> String {
    let date = Utc::now().format("%Y%m%d_%H%M%S");
    format!("{}_{}_{}.{}", case_id, doc_type, date, 
            match doc_type {
                "evidence_list" => "xlsx",
                "timeline" => "png",
                "report" => "pdf",
                _ => "pdf",
            })
}
```

## 四、文件上传与解析流程

### 4.1 上传流程

```rust
// src/routers/files.rs
use axum::{extract::Multipart, http::StatusCode};
use tokio::fs::File;
use tokio::io::AsyncWriteExt;

/// 上传文件
pub async fn upload_file(
    State(state): State<Arc<AppState>>,
    ctx: AppContext,
    case_id: String,
    mut multipart: Multipart,
) -> Result<Json<EvidenceFile>> {
    // 1. 接收文件
    let field = multipart.next_field().await?;
    let original_name = field.file_name().unwrap_or("unknown").to_string();
    let file_type = field.content_type().unwrap_or("application/octet-stream").to_string();
    let data = field.bytes().await?;
    
    // 2. 生成存储路径
    let stored_name = generate_stored_name(&original_name);
    let storage_path = format!("files/{}/{}", case_id, stored_name);
    let full_path = state.config.storage_root.join(&storage_path);
    
    // 3. 确保目录存在
    tokio::fs::create_dir_all(full_path.parent().unwrap()).await?;
    
    // 4. 保存文件
    let mut file = File::create(&full_path).await?;
    file.write_all(&data).await?;
    
    // 5. 计算文件哈希（用于去重）
    let file_hash = calculate_sha256(&data);
    
    // 6. 创建数据库记录
    let evidence = state.db
        .create_evidence(EvidenceFile {
            id: generate_id(),
            case_id: case_id.clone(),
            original_name,
            stored_name,
            file_type,
            file_size: data.len() as i64,
            storage_path,
            storage_hash: Some(file_hash),
            uploaded_by: ctx.user_id,
            ..Default::default()
        })
        .await?;
    
    // 7. 异步解析（不阻塞响应）
    let parser = state.parser.clone();
    let db = state.db.clone();
    let evidence_id = evidence.id.clone();
    tokio::spawn(async move {
        match parser.parse_file(&evidence).await {
            Ok(result) => {
                let _ = db.update_parsed_result(&evidence_id, &result).await;
            }
            Err(e) => {
                tracing::error!("解析失败 {}: {}", evidence_id, e);
                let _ = db.update_parse_status(&evidence_id, "failed").await;
            }
        }
    });
    
    Ok(Json(evidence))
}
```

### 4.2 解析流程

```rust
// src/services/parser.rs
use serde_json::json;

pub struct FileParser {
    storage_root: PathBuf,
}

impl FileParser {
    /// 解析文件
    pub async fn parse_file(&self, evidence: &EvidenceFile) -> Result<ParsedResult> {
        let file_path = self.storage_root.join(&evidence.storage_path);
        
        let result = match evidence.file_type.as_str() {
            "application/pdf" => self.parse_pdf(&file_path).await?,
            t if t.starts_with("image/") => self.parse_image(&file_path).await?,
            t if t.starts_with("audio/") => self.parse_audio(&file_path).await?,
            "application/vnd.openxmlformats-officedocument.spreadsheetml.sheet" |
            "application/vnd.ms-excel" => self.parse_excel(&file_path).await?,
            _ => self.parse_generic(&file_path).await?,
        };
        
        // 保存解析结果
        let json_path = self.storage_root
            .join("parsed")
            .join(&evidence.case_id)
            .join(format!("{}.json", evidence.id));
        
        tokio::fs::create_dir_all(json_path.parent().unwrap()).await?;
        tokio::fs::write(&json_path, serde_json::to_string_pretty(&result)?).await?;
        
        Ok(result)
    }
    
    /// 解析 PDF
    async fn parse_pdf(&self, path: &Path) -> Result<ParsedResult> {
        let doc = PdfDocument::open(path)?;
        
        let mut pages = Vec::new();
        let mut full_text = String::new();
        
        for (i, page) in doc.pages().enumerate() {
            let text = page.text();
            let blocks = self.extract_blocks(&page);
            
            pages.push(json!({
                "page_num": i + 1,
                "text": text,
                "width": page.width(),
                "height": page.height(),
                "blocks": blocks,
            }));
            
            full_text.push_str(&text);
        }
        
        Ok(ParsedResult {
            file_type: "application/pdf".to_string(),
            full_text,
            page_count: Some(doc.page_count()),
            pages,
            extracted_entities: self.extract_entities(&full_text),
            anchor_index: self.build_anchor_index(&pages),
        })
    }
    
    /// 解析音频
    async fn parse_audio(&self, path: &Path) -> Result<ParsedResult> {
        // 调用 FunASR 进行语音识别
        let transcription = self.asr.transcribe(path).await?;
        
        let segments = transcription.segments
            .iter()
            .map(|seg| json!({
                "start": seg.start,
                "end": seg.end,
                "text": seg.text,
            }))
            .collect();
        
        Ok(ParsedResult {
            file_type: "audio/mpeg".to_string(),
            full_text: transcription.text,
            duration: Some(transcription.duration as i64),
            pages: vec![json!({
                "segments": segments
            })],
            extracted_entities: self.extract_entities(&transcription.text),
            anchor_index: self.build_timestamp_index(&transcription.segments),
        })
    }
}
```

```rust
// src/services/jump.rs

/// 获取节点的跳转目标
pub async fn get_jump_targets(
    db: &Database,
    node_id: &str,
) -> Result<Vec<JumpTarget>> {
    // 1. 获取节点关联的所有证据
    let links = db.get_node_links(node_id).await?;
    
    let mut targets = Vec::new();
    
    for link in links {
        let evidence = db.get_evidence(&link.evidence_id).await?;
        
        // 2. 根据锚定类型构建跳转目标
        let target = match link.anchor_type {
            "page" => {
                let page_num = link.anchor_data["page_num"].as_u64().unwrap();
                JumpTarget {
                    evidence_id: evidence.id,
                    evidence_name: evidence.original_name,
                    file_type: evidence.file_type,
                    storage_path: evidence.storage_path,
                    location: JumpLocation::Page(page_num),
                }
            }
            "timestamp" => {
                let seconds = link.anchor_data["seconds"].as_f64().unwrap();
                JumpTarget {
                    evidence_id: evidence.id,
                    evidence_name: evidence.original_name,
                    file_type: evidence.file_type,
                    storage_path: evidence.storage_path,
                    location: JumpLocation::Timestamp(seconds),
                }
            }
            "paragraph" => {
                let start = link.anchor_data["start"].as_u64().unwrap() as usize;
                let end = link.anchor_data["end"].as_u64().unwrap() as usize;
                JumpTarget {
                    evidence_id: evidence.id,
                    evidence_name: evidence.original_name,
                    file_type: evidence.file_type,
                    storage_path: evidence.storage_path,
                    location: JumpLocation::Paragraph(start, end),
                }
            }
            _ => continue,
        };
        
        targets.push(target);
    }
    
    Ok(targets)
}

/// 跳转位置
#[derive(Debug, Clone)]
pub enum JumpLocation {
    Page(u32),
    Timestamp(f64),
    Paragraph(usize, usize),
    Coordinate(f64, f64, f64, f64),
}
```

```rust
                                    JumpLocation::Coordinate(x, y, w, h) => {
                                        Some((*x, *y, *w, *h))
                                    }
                                    _ => None,
                                },
                            }
                        }
                    } else {
                        rsx! {
                            div { class: "unsupported",
                                "不支持预览的文件类型"
                            }
                        }
                    }
                }
                _ => rsx! { div { "加载中..." } }
            }
        }
```

```rust
// src/services/export.rs

/// 导出证据清单
pub async fn export_evidence_list(
    db: &Database,
    case_id: &str,
    node_ids: Option<Vec<String>>,
) -> Result<ExportRecord> {
    // 1. 获取案件信息
    let case_info = db.get_case(case_id).await?;
    
    // 2. 获取节点列表
    let nodes = if let Some(ids) = node_ids {
        db.get_nodes_by_ids(&ids).await?
    } else {
        db.get_all_nodes(case_id).await?
    };
    
    // 3. 获取每个节点关联的证据
    let mut evidence_map = HashMap::new();
    for node in &nodes {
        let links = db.get_node_links(&node.id).await?;
        for link in links {
            evidence_map.entry(link.evidence_id.clone())
                .or_insert_with(Vec::new)
                .push(node.clone());
        }
    }
    
    // 4. 获取证据详情
    let evidence_list = Vec::new();
    for (evidence_id, related_nodes) in evidence_map {
        let evidence = db.get_evidence(&evidence_id).await?;
        evidence_list.push(ExportEvidence {
            original_name: evidence.original_name,
            file_type: evidence.file_type,
            page_count: evidence.page_count,
            related_nodes: related_nodes.iter().map(|n| n.title.clone()).collect(),
            upload_date: evidence.uploaded_at,
        });
    }
    
    // 5. 生成 Excel
    let excel_data = generate_evidence_list_excel(&case_info, &evidence_list);
    
    // 6. 保存导出文件
    let file_name = generate_export_name(case_id, "evidence_list");
    let storage_path = format!("exports/{}/{}", case_id, file_name);
    let full_path = CONFIG.storage_root.join(&storage_path);
    
    tokio::fs::create_dir_all(full_path.parent().unwrap()).await?;
    tokio::fs::write(&full_path, excel_data).await?;
    
    // 7. 创建导出记录
    let record = db
        .create_export_record(ExportRecord {
            id: generate_id(),
            case_id: case_id.to_string(),
            export_type: "evidence_list".to_string(),
            file_name,
            storage_path,
            file_size: Some(excel_data.len() as i64),
            generated_by: "system".to_string(),
            node_ids: Some(json!(nodes.iter().map(|n| &n.id).collect::<Vec<_>>())),
            evidence_ids: Some(json!(evidence_map.keys().collect::<Vec<_>>())),
        })
        .await?;
    
    Ok(record)
}
```

```rust
pub fn generate_signed_url(
    evidence_id: &str,
    user_id: &str,
    expires_in: Duration,
) -> String {
    let expires = Utc::now() + expires_in;
    let signature = calculate_signature(evidence_id, user_id, &expires);

        "/api/v1/files/{}/download?signature={}&expires={}",
        evidence_id,
        signature,
        expires.timestamp()
    )
}
```

```rust
pub async fn verify_file_integrity(
    db: &Database,
    evidence_id: &str,
) -> Result<bool> {
    let evidence = db.get_evidence(evidence_id).await?;
```

## 十、总结

### 10.1 关键设计决策

| 问题 | 方案 | 理由 |
|------|------|------|
| 原始文件如何存储 | 文件系统 + 数据库记录 | 大文件不适合存数据库 |
| 如何关联节点与证据 | 关联表 + 锚定信息 | 支持双向跳转 |
| 解析结果存哪里 | JSON 文件 + 数据库索引 | 灵活查询 + 快速检索 |
| 如何保证文件安全 | 哈希校验 + 签名链接 | 防篡改 + 防外链 |
| 导出资料如何管理 | 导出记录表 | 可追溯 + 可复用 |
